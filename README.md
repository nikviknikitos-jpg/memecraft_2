# MemeCraft Universe (Fabric 1.20.1)

## Механики
- Индусский Моторчик + Покрышка -> Бешеное Колесо
- Билетик -> Казино (13x7x13)
- Игровой Автомат + Мем-Монетка -> приз
- Хомяк [Hamster Kombat] -> клик даёт монетку
- Бродяга + Монетка -> Удача III
- Блок Ананаса -> 4 обезьяны с бананами
- Червь, Мимик, Аномалия -> яйца призыва
- Телефон РКН -> «Обновить» дважды -> взрыв
- Колода, Кнопка Удачи, Энциклопедия -> ПКМ
